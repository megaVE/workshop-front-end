# Workshop Desenvolvimento Web - Ciência da Computação (Web Development Workshop - Computer Science)
Simple ReactJS project developed to showcase basic concepts of Front End Web Development during the event "Computing Week 2024" in the Federal Univeristy of Alfenas (UNIFAL-MG).
(Projeto simples desenvolvido em ReactJS no intuito de demonstrar conceitos básicos do Desenvolvimento Web Front End durante o evento "Semana da Computação 2024" na Universidade Federal de Alfenas (UNIFAL-MG).)
